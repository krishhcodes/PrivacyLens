ConsentScope · PrivacyLens

ConsentScope Architecture

How site permissions flow from your browser to a local backend that scores them, and how you see and act on the results. Everything runs on your laptop; the only outside call is the optional Google Safe Browsing check.

The pieces

Five parts, one database

Chrome extension (MV3)

Reads and changes each site's location, camera, microphone and notification settings. Records changes as you browse.

extension/ · manifest.json, sw.js, watch.js, bridge.js, popup

Local scanner

One-off import of every saved site rule in Chrome, Edge and Brave on this laptop.

scanner/scan.py

Backend API

Stores audits, infers each site's purpose, finds mismatches, analyzes policies, scores risk, checks Safe Browsing.

backend/ · FastAPI + SQLite · 127.0.0.1:8000

PrivacyLens website

Command Centre, Privacy Scanner, Policy Analyzer, Privacy Report, Settings. Refreshes every 5 s.

frontend/ · React + Vite · localhost:5180

Google Safe Browsing

Optional. Flags malware and phishing sites. Only the domains of audited sites are sent; results cached 24 h.

GOOGLE_SAFE_BROWSING_API_KEY in backend/.env

User workflow

Setting up, once

  1. Load the extension: chrome://extensions → Developer mode → Load unpacked → consentscope\extension.
  2. Optional: put your Google Safe Browsing key in backend\.env.
  3. Start the backend: double-click backend\run.bat (keep the window open).
  4. Start the website: npm run dev in frontend, then open http://localhost:5180 in the same browser as the extension.
  5. Optional: import existing rules with python scanner\scan.py.

Scoring

Where the points come from

SignalSourcePoints
Location, camera or microphone allowedBrowser setting12 each
Notifications allowedBrowser setting4
Permission doesn't fit the site's purposeKeyword purpose + rule table20 high / 8 review (replaces the above)
Policy declares sale of dataPolicy rules18
Policy declares third-party sharingPolicy rules12
Vague retention / no deletion routePolicy rules8 each
Listed by Google Safe BrowsingGoogle API50

Score = sum, capped at 100. Bands: 0–24 low, 25–49 moderate, 50–74 elevated, 75–100 high. The Command Centre health number is 100 minus the average site score. No AI model is involved; every point traces to one setting or one sentence.
